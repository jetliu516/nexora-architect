面向住宅设计的浏览器工作台与iPhone/iPad工程。基于Chief Architect公开工作流独立实现；当前已重构为墙段、洞口、楼层驱动的建筑模型，尚未达到Chief Architect全量1:1。

**实现与验证：** [Studio2记录](docs/Studio2-实现与验证.md)

**完整对标研究：** [功能验收矩阵](docs/Chief-Architect-功能验收矩阵.md)

## 使用

本机运行 `python3 -m http.server 8772 --directory dist`，打开 `http://127.0.0.1:8772`。网页没有构建步骤，3D库已打包，首次加载后可缓存离线资源。

W画墙，D放门，M标尺寸，V选择，Esc结束绘制。点击墙段或构件在右侧改尺寸，拖动墙端点或构件移动。选中墙后可生成连续橱柜。通过上方视图切换平面、3D、立剖面、材料表和图纸。

项目自动保存在当前浏览器，JSON用于完整备份与跨设备。旧版项目会迁移为独立方案；旧版存储键保留。清理浏览器数据前务必导出项目。

## 原生App

打开 `ios/NexoraRoomStudio.xcodeproj`，选择Scheme `NexoraRoomStudio`，选择开发团队与真机后运行。显示名称Nexora Architect，版本2.0.3（构建3），独立Bundle ID `com.nexora.architect.rea`。

iOS未签名编译通过；本次没有签名安装、真机扫描、TestFlight或App Store发布。Android当前使用PWA，没有生成APK。

## 厨卫设计工作区（2026-11-04）

打开「室内与橱柜 → 厨卫样板」创建独立样板，原方案保留在项目库。
选中地柜、吊柜、高柜、中岛、水槽/灶台柜或浴室柜，可设置门抽布局、平板/框式门板、拉手、踢脚、台面厚度/外挑及台面材质。柜高定义为含台面的完成高度。
「柜体展开」显示来自同一部件数据的正面图与尺寸；「柜体表」提供门数、抽屉数、规格、材质及按单柜计算的台面面积，支持 CSV。三维保留 1080p / 1440p / 4K 导出。
沿墙生成支持地柜、抽屉柜、吊柜、高柜及起点偏移；超墙长、超墙高或与墙上门窗相交时整组拒绝，不产生半套柜体。
新增 `node tests/cabinets.test.cjs`：11项柜体几何、真实Three.js网格、保存迁移、数量和冲突检查。
详细验证与限制见 `docs/Kitchen-2026-11-04.txt`。本次保留已发布HD代码，不覆盖 ChiefStudio-REA 工作树中另行开发的 Studio2.1。


## 共享干管与碰撞检查（2026-11-08，2.9.1）

“机电 → 机电工作区”可优化已有六系统线路，预览长度并整步应用/撤销。碰撞检查可定位管线、墙、楼板和构件，跨层立管同步显示在平面、三维与 DXF。自动生成采用共享干管和立管，尚未自动避障或完成工程计算。

该阶段全套检查：`node --test tests/*.test.cjs`，138项通过。详细范围及已知边界见 [路由验证记录](docs/Routing-2026-11-08.txt)。

## 三维路点与受约束绕障（2026-11-08，2.9.2）

选择管线可精确编辑三维路点，或按净距与搜索范围计算绕障候选。预览长度、碰撞和坡度后整步应用，可撤销/重做；支持公制和英制。排水候选检查端点高差和最小坡度，已有墙洞/楼板洞可利用。

当前全套检查149项通过，完成桌面及390像素窄屏浏览器验收，中文、英文和西班牙文的新界面已验证。受限搜索不保证全局最优或找到所有解，不自动建洞口，工程计算仍待完成。详见[绕障验证记录](docs/Avoidance-2026-11-08.txt)。

## 排水纵剖面（2026-11-08，2.9.3）

机电工作区可选择起止节点生成已有排水路径的展开纵剖面，查看真实标高、坡度、竖向落差和问题位置，导出SVG与逐段CSV。管线属性支持单管查看。多路径按三维长度选最短已有路径，不修改管线。

当前159项全套测试通过，实际下载的数据与模型计算一致，中英西及390像素窄屏通过。纵剖面尚未作为关联视口纳入图纸布局；工程计算及真机交付仍待完成。详见[纵剖面验证记录](docs/Profile-2026-11-08.txt)。

## AI 机电修改（2026-11-08，2.9.4）

机电工作区和节点/管线属性中打开“AI 机电修改”，用自然语言提出管径、坡度、标高、负荷、绕障或系统生成/优化要求。先检查实际差异和碰撞结果，再整步应用，支持撤销、重做及JSON记录导出。当前接入gpt-6.1-sol，限定作用范围，重建既有系统需要在界面勾选。

172项全套测试通过；10项真实模型固定评测全部通过，含中英西、英寸换算、拒绝无依据管径及越权重建，评分同时检查未请求的附带修改。实际网页验证32毫米管径、绕墙、撤销/重做和刷新保存。AI尚不进行工程计算，全产品对标仍未完成。详见[AI机电验证记录](docs/AI-MEP-2026-11-08.txt)。

## 机电预留与套管（2026-11-08，2.9.5）

按管线路径预览并生成穿墙/穿楼板矩形预留，真正扣除宿主实体；套管参与碰撞和绕障。支持尺寸编辑、关联失配提示、三维定位、撤销/重做、CSV清单及DXF外框。191项全套测试通过，完成两层样板的实际浏览器操作、中英西/英制和手机验收。

防火封堵目前支持施工备注，结构开孔及防火性能核定尚未完成。详见[预留验证记录](docs/Penetrations-2026-11-08.txt)。
